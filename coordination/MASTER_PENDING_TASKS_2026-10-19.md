## Priority meaning and state

- **P0**: protect user leads, production safety, source/release correctness or missing critical assets. **P1**: verified high-impact SEO, content, conversion or UI integration. **P2**: new content/creative/marketing subject to P0/P1; **P3**: experiments/review-only.
- State: **BLOCKED** (specific gate missing), **REVIEW** (existing issue/PR or draft; no release), **QUEUED** (ready for an unclaimed worker), **VERIFY** (reported but current state or deployment not proven), **COMPLETE** only with exact integration/QA evidence.
- A task having an existing PR is **REVIEW**, not a request to reimplement. No production action, bulk branch merges, fabricated testimonials, unapproved image rights, or Search Console success claims.
